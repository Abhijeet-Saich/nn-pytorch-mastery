Ten-Character Bigram

The same model as my_llm_1.ipynb, shrunk to a 10-character vocabulary so every number fits on screen. Everything below is computed live in your browser: a real embedding table, a real cross-entropy loss, real sampling and real training.

Notebook shapes: vocab_size = 65, B = 32, T = 8. Here: vocab_size = 10, B = 2, T = 4 for display (training below uses B = 32, T = 8).

1Vocabulary

Collect every distinct character in the text and sort them. Each one's position in the sorted list becomes its id. Our toy corpus has exactly 10 distinct characters. ↵ is the newline and ␣ is the space.

chars = sorted(list(set(text)))     # 10 unique characters
stoi  = {ch: i for i, ch in enumerate(chars)}
itos  = {i: ch for i, ch in enumerate(chars)}

Why is ↵ first? Sorting uses character codes: newline is 10, space is 32, ! is 33, and letters start at 97.

2encode / decode

Type something. encode looks up each character in stoi. decode maps the ids back through itos. Only the 10 vocab characters can be encoded. Anything else is a KeyError in Python.

encode = lambda s: [stoi[c] for c in s]
decode = lambda l: ''.join([itos[i] for i in l])

encode(s)

decode(encode(s))

3Tensor and 90/10 split

The whole text becomes one long 1-D tensor of ids (torch.long, because ids are used as indices). The first 90% is for training. The last 10% is held out to check generalisation. There's no shuffling: it's a straight cut.

data = torch.tensor(encode(text), dtype=torch.long)
n = int(0.9 * len(data))
train_data, val_data = data[:n], data[n:]

4get_batch: the shift by one

Pick B = 2 random start positions i. Read T + 1 = 5 characters from each one. x is the first 4 and y is the last 4, so y is x shifted left by one. Each y[t] is the character that follows x[t].

ix = torch.randint(len(d) - block_size, (batch_size,))
x  = torch.stack([d[i  :i+block_size  ] for i in ix])   # (B, T) = (2, 4)
y  = torch.stack([d[i+1:i+block_size+1] for i in ix])   # (B, T) = (2, 4)

One row of 4 hides 4 training examples (row b = 0)

5The model is one lookup table

nn.Embedding(10, 10) is a 10 × 10 grid of learnable numbers. Row r holds the model's scores (logits) for which character comes after character r. Red means "likely next" and blue means "unlikely next". At the start they're random, drawn from N(0, 1).

self.token_embedding_table = nn.Embedding(vocab_size, vocab_size)  # (10, 10)
logits = self.token_embedding_table(idx)                         # (B,T) → (B,T,C) = (2,4,10)

Click any token in x. The lookup copies that token's row out of the table into the logits tensor. Every one of the 2 × 4 = 8 tokens gets its own row, which is how the shape (2, 4) grows a third axis, C = 10.

6The loss: cross-entropy

F.cross_entropy wants a flat list of rows, so (2, 4, 10) is reshaped to (8, 10). Each row is softmaxed into probabilities. Then we read off the probability of the true next character (outlined), take −ln of it, and average over all 8 rows.

B, T, C = logits.shape
logits  = logits.view(B*T, C)        # (8, 10)
targets = targets.view(B*T)          # (8,)
loss = F.cross_entropy(logits, targets)   # mean of −ln p(target)

7Journey of one example: forward, loss, backward, update

Follow one (input, target) pair through a complete training step. A real batch does this for all B × T pairs at once and averages the gradients, but every pair takes exactly this path. This section uses its own copy of the table, so it won't disturb the model in the other sections.

The path · forward on top, gradients flowing back underneath

x_char, y_char = text[i], text[i+1]           # one (input, target) pairidx, targets = tensor([[stoi[x_char]]]), tensor([[stoi[y_char]]])logits = self.token_embedding_table(idx)      # (1, 1, 10)logits, targets = logits.view(1, 10), targets.view(1)probs = F.softmax(logits, dim=-1)             # happens inside cross_entropyloss = -probs[0, targets].log()              # = F.cross_entropy(logits, targets)optimizer.zero_grad(); loss.backward()        # ∂L/∂logits = probs − onehot(y)                                              # ∂L/∂W[idx] += ∂L/∂logits  (other rows: 0)optimizer.step()                              # W -= lr * W.grad   (plain SGD here)logits, loss = model(idx, targets)            # forward again: loss is lower

9Training

Each step samples a batch (B = 32, T = 8), computes the loss, backpropagates and lets AdamW nudge the table. Watch the left heatmap (the model's probabilities, softmax of each row) slowly turn into the right one (the true bigram frequencies counted from train_data). When training finishes, sections 5, 6 and 8 above use the trained table, and section 7 can copy it.

for step in range(max_iters):
    xb, yb = get_batch('train')
    logits, loss = model(xb, yb)
    optimizer.zero_grad(set_to_none=True)
    loss.backward()        # dloss/dW[r, c] = p(c | r) − 1[c is target], averaged
    optimizer.step()
